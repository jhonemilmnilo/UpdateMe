# AGENTS.md — Development Guidelines for update_me

This project follows:
- The **Project Rules & Communication Protocol** defined in [.agents/rules/project-protocol.md](file:///.agents/rules/project-protocol.md).
- The **Supreme Engineering & Karpathy Guidelines** defined in [.agents/rules/karpathy-flutter.md](file:///.agents/rules/karpathy-flutter.md).
- The **Storm Cloud Green Design System** defined in [.agents/rules/theme-storm-cloud-green.md](file:///.agents/rules/theme-storm-cloud-green.md).

## Core Principles
1. **Strict Code Gate**: Do NOT generate or drop code until user explicitly says "proceed", "implement", "go ahead", or "execute".
2. **No Icons & No Unnecessary Cards**: Rely on clean typography, generous whitespace, and minimalist badges. Avoid boxed card wrappers for text.
3. **Think Before Coding**: Clarify data flows and architectural decisions with the user first.
4. **Simplicity First**: Write clean, surgical, non-bloated Dart/Flutter code. Avoid premature complexity.
5. **Widget Performance**: Strictly optimize image sizes and Android `RemoteViews` layouts to preserve memory and battery life.
6. **Storm Cloud Green Aesthetic**: `#4E5A54`, `#6E7A70`, `#2E3832`, `#8E9A8E`.
7. **Mentor Mentality**: High-signal, compact TagLish (conyo style). Zero fluff.
