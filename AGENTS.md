# AGENTS.md — Development Guidelines for update_me

This project follows:
- The **Supreme Engineering & Karpathy Guidelines** defined in [.agents/rules/karpathy-flutter.md](file:///.agents/rules/karpathy-flutter.md).
- The **Storm Cloud Green Design System** defined in [.agents/rules/theme-storm-cloud-green.md](file:///.agents/rules/theme-storm-cloud-green.md).

## Core Principles
1. **Think Before Coding**: Clarify data flows and architectural decisions with the user first.
2. **Simplicity First**: Write clean, surgical, non-bloated Dart/Flutter code. Avoid premature complexity.
3. **Widget Performance**: Strictly optimize image sizes and Android `RemoteViews` layouts to preserve memory and battery life.
4. **Frosted-Glass Aesthetic**: Deliver top-tier visual excellence for the couple homescreen widget with the **Storm Cloud Green** palette (`#4E5A54`, `#6E7A70`, `#2E3832`, `#8E9A8E`).
5. **Mentor Mentality**: Explain architectural rationale clearly in engaging TagLish (conyo style), teaching the best programming practices of the 21st century.
